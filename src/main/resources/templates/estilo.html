Estrutura

.container já envolve todo <main>. Comece a página com .pagina-cabecalho (com h1, .subtitulo e .acoes), agrupe com .secao + .secao-titulo, use .grade para cards e .pilha para empilhar com espaçamento.

Botões

Todo botão tem pelo menos 44 px de altura; .btn-grande ocupa a largura toda com 56 px. Ações destrutivas (encerrar, excluir) usam .btn-perigo.

Status

As cores seguem o diagrama de estados: cinza (configurando), verde (recebendo votos), amarelo (aguardando apuração) e gramado (resultado publicado). Pelo status do domínio:

<span th:replace="~{fragments/componentes :: badgeVotacao(${votacao.status()})}"></span>

    Como usar o layout

    <!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org"
      th:replace="~{fragments/layout :: layout(~{::title}, ~{::main}, ~{::link})}">
<head>
  <title>Nova votação</title>            <!-- vira "Nova votação · VAR" -->
  <link rel="stylesheet" th:href="@{/css/organizador.css}"> <!-- sem CSS extra: ~{} -->
</head>
<body><main> … conteúdo … </main></body>
</html>
    • Datas e números: ${@fmt.dataHora(instante)}, ${@fmt.percentual(0.667)}, ${@fmt.numero(12.5)}, ${@fmt.statusVotacao(v.status())}.
    • Votacao não é thread-safe: leia e escreva dentro de synchronized (votacao).
